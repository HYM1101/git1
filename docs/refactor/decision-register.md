## 已作出的工程决策

2. HTML 视觉真值为根目录 `demo-pc-*.html`，视觉令牌以 `PC端视觉规范.md` 为准。
3. CSS 命名沿用语义化局部类名；新公共布局采用 `app-shell__*` BEM 前缀。
4. 未确认事项只阻塞其直接依赖任务，不阻塞本地质量加固和视觉基础层改造。
